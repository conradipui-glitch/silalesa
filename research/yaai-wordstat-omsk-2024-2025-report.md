## Вывод и ограничения

- Кровельные работы лидируют среди выбранных формулировок с января по август, полусухая стяжка — с сентября по декабрь.
- Сила разрыва меняется. Для прямых заходов не следует автоматически заменять основной оффер одной категорией.
- Все фразы предварительные: «кровельные работы», «полусухая стяжка», «фасадные работы» могут отличаться по объёму информационных и коммерческих намерений, а «металлоконструкции на заказ» не охватывает весь спрос на монтаж.
- Результаты **не складываются** в общий размер рынка: запросы пересекаются, от одного человека может быть несколько запросов, спрос Wordstat не равен заявкам.
- Перед активацией сезонной логики нужно повторить семантический отбор, сверить реальные обращения/рентабельность/доступность бригад, определить запасной нейтральный оффер. Сайт может использовать отдельные микространицы для точных направлений без автоматического сезонного H1.
- Сезонная конфигурация `src/data/seasonal-demand.json` сохраняется `verified:false` до этой проверки.

## Воспроизведение

Исходный открытый манифест находится в `research/yaai-omsk-wordstat-pilot.json`. Использован метод [Yandex AI Studio GetDynamics](https://aistudio.yandex.ru/ru/docs/search-api/api-ref/Wordstat/getDynamics).

Сырые данные `monthly.csv` и `summary.json` доступны как временный workflow artifact в указанном запуске GitHub Actions (срок хранения — 3 дня), без секретов авторизации.

**Статус:** исследование первого круга завершено; принятия решений о главном сезонном оффере нет.
