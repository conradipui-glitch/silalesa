# SEO-итерация для Яндекса: ремонтные статьи, волна 1

Дата: 8 октября 2026. Источник методики: [rdsolod-ui/claude-yandex-seo](https://github.com/rdsolod-ui/claude-yandex-seo/blob/main/skills/yandex-seo/SKILL.md).

## Контекст и доказательства

- Регион бизнеса — Омск/Омская область, цели — полезные ответы и обращения по услугам.
- Действующие страницы уже имеют JSON-LD Article/FAQPage, канонические URL, FAQ, исходные сравнения и пререндер без JS. Поэтому массовый SEO-рерайт разрушил бы часть полезного контента.
- Внутреннее исследование `research/yaai-wordstat-omsk-2024-2025-report.md`: за 24 месяца по **выбранным общим формулировкам** полусухой стяжки — 9 942, механизированной штукатурки — 1 675. Это относительный сигнал для выбора *темы*, но **не** оценка трафика, позиций, полезности отдельных вопросных запросов или заказов.
- Прямой срез Яндекс.Вебмастера и текущая выдача по информационным кластерам в этой итерации не выгружались. Улучшения по метаданным и внутренним связям основаны на аудите текущих страниц, а не на недоказанных позициях.

## Проверка

`npm run build` включает `scripts/check-seo-articles-wave1.mjs` и все прежние регрессионные проверки. Отдельная проверка сверяет итоговые Title/Description с учётом overrides, H1, canonical, Article/FAQ JSON-LD и ссылки на родственные темы в no-JS HTML.

**Актуализация от 08.10.2026:** проверка источников и готовность следующего этапа теперь оформлены в [YANDEX-SEO-NEXT-WAVE.md](./YANDEX-SEO-NEXT-WAVE.md). Повторный массовый рерайт пока не запускался.

## Следующая итерация — только после фактического исследовательского среза

1. Из `yaai` получить группировку реальных запросов и кластеров, сопоставление запрос → URL по Яндекс.Вебмастеру (если OAuth-доступ настроен), Search API выдачу и страницы конкурентов в регионе. Не тратить бюджет на широкий SERP-сбор без лимитов и цели.
2. Проверить каннибализацию коммерческого URL услуги vs информационного гайда, реальные показы/CTR, индексирование, мобильные входы и обращения. Данные запросов с менее чем 10 визитами в Метрике могут быть скрыты; основной источник поисковых запросов — Вебмастер.
3. Затем взять следующую партию статей о банях, оставив отдельные кластеры: выбор модели, покупка и цена, доставка и установка, приёмка. Не делать все страницы «баня в Омске» по одному шаблону.
4. Публикация сама по себе не гарантирует рост позиций; сравнить периоды после переобхода с учётом сезонности.
