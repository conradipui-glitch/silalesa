## Редакторский порядок

1. Получить подтверждение конкретного пункта от уполномоченного представителя без передачи секретов или личных документов в публичный PR.
2. Привязать каждый опубликованный факт к подтверждённому источнику и дате; при необходимости оформить ссылку на публичный источник.
3. Сохранить ранее подтверждённые требования к правдивости цен/комплектации и добавить действительно актуальные данные только после проверки.
4. Для настоящих кейсов показывать задачу, год/город без персональных данных, роль команды, объём, сложность, фото этапов с разрешением и результат — без придуманного экономического эффекта.
5. Для новых статей о грунтах, фундаментах, зимних работах и инженерных вопросах применять проверенные нормативные источники и техническую рецензию; не заменять проект советом из статьи.
6. Прогнать browser/SEO smoke, пересмотреть микроформулировки на мобильном, только затем сливать PR.
