# Замена четырёх фотографий бань — R3

Обновлены изображения в карточках товаров. Загружены оригинальные фотографии пользователя, проверены по SHA-256, уменьшены до ширины не более 1280 пикселей и оптимизированы в WebP (качество 79). Изображения находятся непосредственно в `src/assets/img/`, а не зависят от внешнего CDN при просмотре сайта.

| Карточка | Файл |
|---|---|
| Каркасная 5,5×2,2 | `src/assets/img/karkasnaya-5-5.webp` |
| Квадро 3×2 | `src/assets/img/kvadro-3x2.webp` |
| Квадро 2×2 | `src/assets/img/kvadro-2x2.webp` |
| Квадро 4×2 | `src/assets/img/kvadro-4x2.webp` |

Заменены ровно четыре импорта в `src/data/products.ts`, сохраняя остальные изображения и данные товаров. Одноразовый workflow для загрузки файлов удалён тем же коммитом, которым сохранены фотографии. Исходные JPG оставлены для совместимости с возможными другими ссылками в проекте.
