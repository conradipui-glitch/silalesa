# Замена четырёх фотографий бань — отдельный запрос во время R3

Пользователь передал четыре новые фотографии (и один снимок текущего блока карточек). Соответствие: 2×2 — девушка у компактной бани; 3×2 — пара у бани в лесу; 4×2 — компания у бани и стола; каркасная 5,5×2,2 — тёмная каркасная баня у воды.

Оптимизированные изображения подготовлены локально в WebP: `kvadro-2x2.webp` (229 746 Б), `kvadro-3x2.webp` (143 640 Б), `kvadro-4x2.webp` (203 640 Б), `karkasnaya-5-5.webp` (150 818 Б). Итого 727 844 Б против около 13,8 МБ исходных PNG. Архив передан пользователю отдельно.

Целевые импорты сейчас в `src/data/products.ts`: `kvadro-2x2.jpg`, `kvadro-3x2.jpg`, `kvadro-4x2-side.jpg`, `karkasnaya-5-5.jpg` в `src/assets/img/`. Не заменять импорты до помещения новых бинарных файлов в GitHub и проверки сборки. Дополнительный аудит показал, что крупные существующие файлы находятся примерно в пределах 300–440 КБ; уже оптимизированные служебные WebP весят существенно меньше. Старые файлы и фото кейсов нельзя массово удалять/пережимать без проверки использования и качества.

Статус: WebP подготовлены, **не загружены в репозиторий и не опубликованы**. Отдельное закрытие этого запроса требуется после фактической загрузки, замены четырёх импортов, визуального контроля карточек, CI и Pages.
