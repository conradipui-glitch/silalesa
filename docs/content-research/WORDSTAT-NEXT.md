## Что именно публикуем

### Гайд по основанию

Гайд строится только на подтверждённых данных компании:

- для стандартных Квадро установка на блоки входит в предложение;
- до доставки согласуются место установки и подъезд;
- при невозможности завезти готовый модуль можно заранее обсуждать сборку на участке;
- сложное основание проверяется отдельно.

Не публикуем как факт универсальное количество блоков, шаг между ними, требования к грунту или единую схему отвода воды: таких подтверждённых параметров в текущих материалах нет.

### Бурение скважин

Существующий коммерческий лендинг усиливается под формулировку `бурение скважин на воду в Омске`, сохраняя только подтверждённые этапы услуги: выбор места, бурение, обсадка, прокачка, насос/оголовок/фильтрация и паспорт скважины.

Не обещаем заранее конкретную глубину, дебит или качество воды: универсальных подтверждённых значений для любого участка в текущих материалах нет.

## Как читать цифры

`Max` — сильнейший отдельный Wordstat-сигнал, который Page Planner использует для приоритета. Похожие запросы не суммируются. Эти числа не являются размером рынка и не гарантируют позиции или трафик.

## Gate после публикации

Зелёный CI подтверждает только то, что приложение собирается и prerender создаёт страницы без технической ошибки. Зелёный GitHub Pages deploy подтверждает публикацию артефакта. Ранжирование, показы, клики и конверсию проверяем отдельно по данным поисковых систем после накопления статистики.
