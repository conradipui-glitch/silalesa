# Визуальный стандарт контентных гайдов «Сила Леса»

Статус: базовая версия, пилот на P02. В следующих итерациях использовать повторно, но не вставлять интерактив в статьи, где он не помогает принять решение.

## Состав материала

1. Содержательный ответ на самостоятельный вопрос пользователя: отдельный URL, title, H1, lead, разбор условий, FAQ и ссылка на соответствующую коммерческую страницу.
2. Как минимум один объясняющий визуальный блок: сравнение двух вариантов, разрез/схема слоёв или последовательность работ. Это схема, а не выдаваемая за объект фотография; обозначать её «условная» и не задавать выдуманные толщины, цены, сроки и результаты измерений.
3. Где есть изменяемые исходные данные — один управляемый мини-интерактив с подписью каждого поля, клавиатурным управлением, отображаемым результатом и оговоркой об ограничениях. Результат — ориентир или список проверок, не автоматический инженерный расчёт.
4. Практический контрольный список, таблица или карточки с критериями приёмки. FAQ должен раскрывать ответы без JavaScript, где возможно.
5. Для технических свойств — ссылки на паспорта конкретных продуктов производителя; не распространять характеристики одного бренда на все смеси и не приписывать компании неуказанные услуги.

## Доступность, SEO и качество

- Сначала контент: текст и ответы должны присутствовать в предварительно сформированном HTML даже без интерактива. React лишь добавляет удобный способ изучить его.
- Адаптивная компоновка без горизонтального скролла у основных карточек; доступные label, минимум 44 px для интерактивных целей, видимый focus, aria-live для изменяемой подсказки, осмысленные описания схем.
- Цвета и типографика берутся из токенов существующего сайта, без нового визуального языка, несогласованной анимации, фиктивных графиков или статистики.
- Фотографии объекта, слайдеры до/после и оригинальные материалы главной не заменять схематическими/сгенерированными изображениями; использовать схемы в статьях дополнительно.
- Пререндиринг, canonical, sitemap, ссылки в обе стороны, TypeScript, сборка и smoke-проверки перед слиянием. Обновлять статусы intent только после фактического подключения и проверки страниц.

## Очередь доработок

P02 — сравнение материалов, схема слоёв, интерактив условий, техкарты (пилот).
S01 — выполнено: сравнение двух технологий, условные этапы и разрез пола, интерактив условий объекта и список проектных проверок. Без выдуманных сроков, толщин и цены.
S04 — интерактивная схема очередности ремонта с исключениями.
P01 — диаграмма этапов нанесения и матрица сопоставления полной сметы.

Любое конкретное число о толщине, времени готовности, влагостойкости, скидках и ценах — только с паспортом конкретного применяемого материала либо подтверждёнными данными компании.
