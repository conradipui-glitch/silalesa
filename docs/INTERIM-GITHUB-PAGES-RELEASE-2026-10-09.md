# Промежуточный релиз строительной версии на GitHub Pages

Дата решения: 9 октября 2026. Владелец прямо разрешил опубликовать сайт **со всеми согласованными изменениями сейчас**, чтобы была живая версия для просмотра и новых итераций до переноса на `.ru`. Это решение заменяет прежнюю временную задержку публикации.

## Объём выпуска

Текущий сайт на `https://conradipui-glitch.github.io/silalesa/` переключается на строительную версию из полной последовательности PR #63–#67: 14 направлений, три подробные услуги, пять статей, улучшенные фотографии, тексты, формы обращения и адаптивность.

Самостоятельная прежняя версия сайта бань **сохранена как исходный код** в ветке `legacy/saunas-site-r10-preserved`; дополнительный снимок — `archive/saunas-site-preserved-20261009`. Эта публикация **не разворачивает** отдельный публичный сайт бань и не гарантирует доступности прежних банных URL. Запросы к удалённым банным путям переходят на статическую страницу HTTP 404 с `noindex`; когда появится адрес банного сайта, согласовать схему переходов.

## Почему исправлен deploy workflow

- GitHub Pages использует путь `/silalesa/`; прежняя сборка выполнялась с Vite `base=/` и могла отображать неработающие маршруты. Новый `.github/workflows/pages.yml` задаёт `GITHUB_PAGES=true`.
- Сценарий `scripts/prerender.mjs` сам создаёт полезный `404.html` с `noindex`; workflow больше не перезаписывает его копией домашней страницы.
- `scripts/check-r10-live.mjs` проверяет **10 строительных канонических страниц, три алиаса, исключение банных страниц, sitemap, robots, llms.txt и HTTP 404**. Он выполняется после успешного деплоя — это проверка реального опубликованного сайта, а не исходных файлов.

## Далее

Публичный адрес GitHub Pages оставляем технической живой демонстрацией. Правки, подтверждение контактных номеров/цен/изображений, будущее размещение бань и перенос SEO на `.ru` — отдельные задачи. **Метрику не подключать**, пока заказчик не согласует сайт и окончательный домен. Никакой подмены `.ru`-canonical заранее.
