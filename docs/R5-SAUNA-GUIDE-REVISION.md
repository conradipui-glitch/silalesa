# R5 — четыре гайда «выбор и покупка»

## Охват

- `/guides/bani/kvadro-ili-karkasnaya/`: выбор по числу помещений, цены четырёх подтверждённых моделей, прямые карточки и контакт.
- `/guides/bani/chto-vhodit-v-tsenu/`: включённое в стандарт Квадро отдельно от опций и нестандартной доставки/монтажа; три модели и запрос состава заказа.
- `/guides/bani/kak-vybrat-razmer-2x2-3x2-4x2/`: реальные внутренние размеры и число помещений вместо выдуманной вместимости; три модели и выбор размера.
- `/guides/bani/gotovaya-ili-stroit/`: честная развилка «готовая Квадро / строительство по индивидуальному проекту», без вымышленной цены строительства. Подробная шестистрочная таблица по желанию, после короткого ответа и моделей.

## Решения

Источники чисел и моделей — `src/data/products.ts` и коммерческие URL в `src/data/seo-pages.json`. Общий реестр карточек — `src/data/sauna-choice-models.json`; отдельная проверка R5 сверяет ID, цены и URL с продуктами. Текстовые правки изолированы в `seo-page-overrides-r5.json` и не затрагивают услуги или четыре гида R1–R4.1. Ранний CTA не требует заполнения анкеты, ведёт на WhatsApp компании с конкретным вопросом и URL текущего гайда. У каждой модели — собственная ссылка через роутер, учитывающий базовый путь GitHub Pages. Контент, цены, вопросы, ссылки и CTA отображаются также в prerender без JavaScript.

Сроки, индивидуальное строительство и его стоимость, вместимость «N человек», гарантия, доставка каркасной бани по условиям Квадро и доплаты не представлены как подтверждённые факты.

## Проверка и ограничения

Постоянный тест `scripts/check-r5.mjs` включён в `npm run build`; проверяются четыре страницы и 22 основных URL по существующим тестам, цены относительно исходных карточек, ссылки, CTA, порядок содержимого и no-JS. Перед объявлением R5 полностью принятой отдельно необходимы реальный просмотр mobile/desktop владельцем и практическая проверка открытия WhatsApp: сборка не заменяет эти действия. PR, CI и публикация подтверждаются историей GitHub после выполнения, не заранее.
