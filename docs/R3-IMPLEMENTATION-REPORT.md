# R3 — три ремонтных гайда: отчёт о реализации

Страницы: P02 `guides/remont/gipsovaya-ili-tsementnaya-shtukaturka`, S01 `guides/remont/polusuhaya-ili-mokraya-styazhka`, S04 `guides/remont/shtukaturka-ili-styazhka-chto-snachala`.

## Изменено

- P02: прямой ответ для сухой комнаты, ванной и фасада; нейтральные начальные поля, ориентир после первого выбора, проверки основания и отделки, контекстный путь к расчёту механизированной штукатурки.
- S01: короткая разница между полусухой и мокрой стяжкой; первый результат после указания типа пола; уточнения доступа и покрытия; CTA только на заявленную услугу полусухой стяжки.
- S04: сценарии «мокрая штукатурка», «стяжка уже готова», «ГКЛ» не подставляются за посетителя; маршрут с этапами, точками передачи, защитой, тёплым полом и мокрыми зонами; ссылки на две самостоятельные услуги без обещания единого подряда.
- Тексты и четыре быстрых тезиса определены в отдельном реестре overrides; прежние подробные разделы сокращены без вымышленных цен, сроков или характеристик.
- HTML без JavaScript получает синхронизированные SEO, lead, summary, разделы, сценарии, ссылки на услуги и рабочий контакт. Проверки R1/R2/R3 выполняются в production build.

## Границы и приёмка

Код R3 — отдельная итерация для трёх ремонтных гайдов. Замена четырёх фотографий бань — дополнительный запрос, не часть содержания гайдов. Четыре изображения подготовлены в оптимизированном WebP-архиве, но до фактической загрузки бинарных файлов и замены импортов нельзя считать замену опубликованной. Не отмечать это выполненным без проверки.

Заполнить номера PR и Pages run после фактической проверки CI и публикации. Визуальный мобильный рендер и отправка WhatsApp вручную не подтверждены.
