# R6 — итог релиза четырёх практических гайдов

Обновлены существующие URL: `/guides/bani/fundament-dlya-mobilnoy-bani/`, `/guides/bani/podgotovka-uchastka-dostavka-manipulyator/`, `/guides/bani/chek-list-priemki-gotovoy-bani/`, `/guides/uchastok/kogda-burit-skvazhinu/`. Новые конкурирующие SEO-страницы не создаются.

Пользователь сразу видит короткий ответ, подтверждённую цену Квадро от 230 000 ₽ либо бурения от 2 500 ₽/пог. м, конкретный CTA в WhatsApp и переход к каталогу или услуге. Каждый гайд даёт три сценарных шага «что сделать → что показать → что получите», полезные соседние ссылки и необязательные подробные инструкции там, где они существовали. Печатный чек-лист приёмки и полный состав его пунктов сохранены по прежнему адресу.

В React и статическом HTML использован общий JSON с четырьмя override. Постоянный `scripts/check-r6.mjs` проверяет цены, CTA, полноту шагов, SEO, links, статический HTML, безопасность и печатный список. Предыдущие регрессии R1–R5 и исправление pre-R6 остаются обязательными в `npm run build`.

Не обещаем универсальный срок изготовления, гарантированный дебит/глубину скважины, технические параметры опор или манипулятора без проверки. Услуги и нестандартные условия согласуются отдельно. Перед фактической приёмкой остаётся ручной просмотр на мобильном/десктопе, переходы по ссылкам в браузере и реальная отправка WhatsApp. Публикацию отмечаем выполненной только после успешного Pages deploy.
