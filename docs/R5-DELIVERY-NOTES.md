# R5 — передача четырёх гайдов

Подготовлены четыре существующих гайда о выборе бани: Квадро/каркасная, состав цены, размеры Квадро и готовая/строить. Клиентский путь: быстрый ответ и стоимость → карточки реальных моделей → три вопроса для расчёта → WhatsApp. Длинная таблица готовая/строить скрыта по умолчанию. Цены, планировки и контакты сверены с реестром `src/data/products.ts`; постоянный `check-r5.mjs` сравнивает модельные ID, исходные цены, ссылки, контент HTML без JavaScript, SEO и CTA.

CI в feature-ветке выполнил `npm ci` и `npm run build` с R1–R5 через Actions run 35464423893; перед merge необходимы PR CI и после merge — main CI/Pages.
