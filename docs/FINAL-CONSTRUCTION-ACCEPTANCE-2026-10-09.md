## Исправлено по итогам приёмки

1. На трёх коммерческих посадочных убрано **повторное предупреждение о ценах**. Осталась одна содержательная строка для конкретной услуги с единицей цены, параметрами расчёта и зависимостями.
2. Из подвала строительной версии удалены прямые переходы на прежний `silalesa55.ru` и `vk.com/silalesa55`, поскольку эти ресурсы не подтверждены как отдельные ресурсы новой строительной версии. Их можно вернуть только после подтверждения владельцем.
3. Из `LocalBusiness` schema.org удалён старый **точный адрес выставочной площадки** (Нефтезаводская, 49/1); для строительной версии оставлены город и регион. Публичный строительный офис/приёмный адрес нельзя утверждать без подтверждения.
4. Добавлен постоянный production-mode тест всех 10 канонических URL.

## Существенные вопросы до публикации

**Блокирует публикацию:**
- Определить **публичный адрес старого сайта бань** и судьбу прежних индексируемых банных URL. Git-ветка `legacy/saunas-site-r10-preserved` сохраняет код, но сама не обеспечивает доступность ссылок/трафика. Обновление сайта без плана миграции может выдавать 404 прежним посетителям.

**Требует подтверждения владельцем до показа как достоверной информации:**
- Проверить, используются ли номера **+7 (913) 688-45-33** (основной) и **+7 (999) 456-33-64** (WhatsApp/дополнительный) именно для строительных заказов. Если линии разделены по нишам, обновить `src/data/products.ts`, `index.html` и все точки связи до релиза.
- Уточнить, имеет ли строительное направление собственный адрес/офис для посетителей. Адрес бывшей площадки бань не возвращать в структурированные данные без подтверждения.
- Сверить все **локальные WebP «в процессе / результат»** с ранее переданными исходными изображениями и подтвердить корректные подписи и принадлежность материалов. Не выдавать пары за реальные кадры одного объекта без доказательств.
- Подтвердить актуальность стартовых цен и реальных направлений работ у заказчика.

**После согласования домена:**
- Настроить новый канонический `.ru`, sitemap, robots, корректные 301/переходы в рамках доступного хостинга; публичный GitHub Pages предпросмотр пока является адресом для проверки.
- Яндекс.Метрику не подключать до одобрения сайта и перехода на согласованный `.ru`.

## Граница тестирования

Локальный Vite preview для неизвестных URL возвращает SPA-fallback с HTTP 200, а GitHub Pages при раздаче `404.html` обычно использует HTTP 404. Мы проверяем наличие статического `404.html` с `noindex` и клиентское состояние «Такой страницы нет», **но итоговые HTTP-статусы и перенаправления после публикации ещё не проверены**. Проверка 100% WCAG, оригинальности изображений или реальных конверсий не проводилась.

## Вердикт

**Технический кандидат готов к просмотру заказчиком после зелёного CI; к окончательной публикации — пока нет.** Оставшиеся вопросы зависят от владельца, реальных контактов, происхождения фото и схемы сохранения отдельного сайта бань.
