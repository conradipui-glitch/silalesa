# Строительный каталог — UX-проход для 14 направлений

Дата: 9 октября 2026. Относится только к строительной версии «Силы Леса». Сохранённая банная ветка `legacy/saunas-site-r10-preserved` не изменялась.

## Цель

В каталоге 14 направлений посетителю было легко выбрать название услуги, но трудно понять, какие данные пригодятся для первой оценки. Общий WhatsApp-текст по всем направлениям не помогал подготовить запрос.

## Исправления

- У каждого направления добавлена короткая строка **«Для первого расчёта»**: полезные исходные данные, характерные для этого вида работ. Это подсказки, а не обязательная форма, не инженерный расчёт и не обещание цены.
- У 12 направлений без собственной подробной посадочной WhatsApp теперь открывается с текстом по выбранной услуге и соответствующими параметрами. Сведения не отправляются автоматически.
- Для механизированной штукатурки и полусухой стяжки сохранены отдельные подробные страницы, без второго конкурирующего коммерческого SEO-URL.
- **Один источник данных** `src/data/construction-services.json` используется в визуальных карточках, пререндере каталога `/services/` и HTML главной страницы без JavaScript.
- Не добавлены цены, гарантии, сроки, отзывы, фотографии, технические свойства или отсутствующие в договоре обязательства компании.

## Источники данных

Параметры для первого контакта — редакционные подсказки, основанные на составе услуг и вопросах, уже отражённых в существующем блоке сметы. Из исследования `yaai` использованы только осторожные практические выводы: для кровли различать монтаж и ремонт, для фасада спрашивать материал стен и вид отделки, для стяжки — площадь/основание/этаж. Не выдаём это за доказанные «боли» реальных клиентов.
