# Сила Леса — master execution plan

Статус: активный план работ. Обновлять по мере выполнения, чтобы не терять незавершённые задачи.

## Правило выполнения

Работаем короткими итерациями. Каждая итерация должна заканчиваться понятным результатом: что изменено, что проверено, что реально опубликовано, что осталось неподтверждённым. Не публикуем неподтверждённые продуктовые/технические обещания ради SEO.
