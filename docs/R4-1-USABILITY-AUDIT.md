# R4.1 — понятность ремонтных гайдов

Дата: 19.09.2026. Источник: замечание владельца после публикации R4; аудит исходного кода компонентов. Визуальную мобильную проверку и фактическую отправку WhatsApp не считать проведёнными без отдельного подтверждения.

## Что исправляем в P01

Маршрут `/guides/remont/mehanizirovannaya-ili-ruchnaya-shtukaturka/` не является коммерческим лендингом `/mehanizirovannaya-shtukaturka-omsk/`. Старый P01 показывал пять переключаемых этапов, выбор одной/двух смет, до восьми строк с выпадающими списками и прогресс «Уточнено 0 из 8». Это проверка состава, а не калькулятор цены; посетитель не обязан разбираться в ней ради первого обращения.

Решение: цена «от 550 ₽/м²» и прямой CTA на первом экране; четыре коротких отличия, пять вопросов к составу сметы без ввода, результат и CTA до технических деталей; сведения о пяти этапах и сравнении двух смет только в добровольно раскрываемых блоках. HTML без JavaScript должен передавать те же ответы и ссылку на реальную услугу. Не обещать конечную цену, сроки и экономию.

## Проверка соседних компонентов по исходникам

- **P02** `PlasterMaterialGuide`: ответ об условиях для гипса/цемента уже дан перед интерактивом; два поясняющих блока, три поля, первый полезный результат после одного выбора помещения, остальные необязательны; `RepairGuideAction` доступен без завершения всех полей. Нет аналогичной матрицы смет.
- **S01** `ScreedComparisonGuide`: сравнение способов видно в первых двух карточках, есть четыре статических критерия, интерактив из трёх полей даёт ориентир после выбора типа пола, остальные поля необязательны; `RepairGuideAction` виден без полного заполнения. Нет восьми повторяющихся статусов по двум подрядчикам.
- **S04** `RenovationSequenceGuide`: основной ответ дан сразу; пользователь выбирает один из трёх описанных маршрутов, дополнительные условия необязательны, затем показывается последовательность; `RepairGuideAction` доступен и до выбора. Здесь выбор определяет содержание схемы и не имитирует стоимость.

Вывод ограничен исходниками: доказанного аналога обязательной матрицы P01 у соседей нет, поэтому в R4.1 не переписываем их без необходимости. В R10 повторно проверить реальные экраны на мобильном и десктопе, клавиатурное управление, переносы, CTA и доступность без JS. Успешная сборка сама по себе не подтверждает удобство на устройстве.
