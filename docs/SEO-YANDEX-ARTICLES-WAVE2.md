# SEO-волна № 2 — четыре ремонтных гайда и маршрут к расчёту

Дата: 10 октября 2026. Область: **только строительный сайт «Сила Леса»**, без бань. Реализация: PR #73. Скилл: [Yandex SEO](https://raw.githubusercontent.com/rdsolod-ui/claude-yandex-seo/main/skills/yandex-seo/SKILL.md), вместе с редакторскими стандартами [Frontend Studio](./FRONTEND-STUDIO-PASS-2026-10-09.md). Результат — более полезные существующие статьи, а не массовое создание URL.

## Почему именно эти страницы

Свежий `yaai`/Wordstat [10 октября](../research/yaai/omsk-calculator-demand-2026-10-10.md) показал запрос «калькулятор стяжки пола»: **85 для Омска / 114 для Омской области**, «калькулятор штукатурки»: **25 / 29**. Эти данные **не являются** измеренными показами, кликами, позициями, лидами или продажами сайта. Регион области включает Омск, а формулировки пересекаются: не суммировать. Конкурентная выдача по строительным расчётам показывает и «мешочные» DIY-калькуляторы, и экспертные услуги; все запросы не следует считать намерением нанять бригаду.

На нашем сайте **уже есть** два самостоятельных бесплатных калькулятора, но три сравнивающих гайда предлагали их довольно поздно — после длинного текста, а гайд об очередности не имел прямой развилки сразу на оба. Содержание четырёх статей до новой волны было предметным и полезным, поэтому новый массив статей/переписывание «под ключевые слова» не требуется.

## Технические проверки

- Тексты изменены в реальном объединяемом JSON-реестре `seo-page-overrides-r3.json` и `seo-page-guides-plaster.json`; React и HTML без JavaScript используют одинаковые формулировки.
- Сводный блок ссылок `guide-estimate-links` на четырёх страницах находится **после краткого ответа и перед длинной частью**; в no-JS HTML гайд об очередности тоже явно ссылается на оба калькулятора.
- `scripts/check-seo-articles-wave2.mjs` проверяет содержание, ссылки, отсутствие дублей URL, SEO и no-JS. Проверка включена в сборку и `test:construction`.
- `scripts/check-construction-final-browser.mjs` проверяет реальные ссылки на соответствующих гайдах на телефоне и широком экране.
- Локальный `GITHUB_PAGES=true npm run build`, CI и Chromium PR #73: **успешно**. Дополнительный ручной Chromium при 390/1440 px: 4/4 страницы HTTP 200, H1 по одному, ссылки 2/1/1/1, горизонтального переполнения и JS-ошибок нет. Сделан визуальный просмотр карточек. Финальная проверка **после публичного деплоя** — отдельно.

## Чего не обещаем и что дальше

Не утверждаем рост органического трафика, позиций и обращений без Яндекс Вебмастера и корректного измерения реальных заявок. Следующая волна — сначала **новое исследование незакрытых покупательских интентов**, подтверждение состава услуг, затем точечное создание страницы, если её запрос нельзя закрыть существующим URL.

Перед переходом на `.ru` нужно согласование заказчика, точных строительных контактов/цен/фото и отдельного адреса прежнего сайта бань. **Яндекс.Метрика на GitHub Pages не подключается** по ранее принятому решению.
